# 🏐 Volleyball Nations League (VNL) 2023 Data Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Volleyball Nations League (VNL) 2023 player statistics dataset using Python. The objective of this analysis is to uncover meaningful insights about player performance, age distribution, attacking ability, blocking strength, serving efficiency, defensive skills, and positional contributions.

Through data cleaning, statistical analysis, and visualization techniques, various performance trends and patterns were identified to better understand the characteristics of elite volleyball players across different countries and positions.

---

## 🎯 Objectives

- Analyze player performance metrics across multiple volleyball skills.
- Identify top-performing players in Attack, Block, Serve, Set, Dig, and Receive.
- Explore relationships between numerical features using correlation analysis.
- Compare player performance based on playing positions.
- Discover patterns related to age and overall performance.
- Generate actionable insights through visualization.

## 🔍 Key Insights

Some notable findings from the analysis include:

- Certain Outside Hitters demonstrated outstanding attacking efficiency.
- Setters dominated the Set statistic while maintaining solid defensive contributions.
- Libero players showed exceptional Dig and Receive performance.
- Strong positive correlations were observed between certain offensive metrics.
- Player age showed varying levels of influence across different skill categories.
- Position-specific strengths were clearly visible throughout the dataset.
